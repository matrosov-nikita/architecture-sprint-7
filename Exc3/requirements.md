### Требования к безопасности:
- Необходимо реализовать механизм сбора согласия на обработку персональных данных от пользователей.
- Данные, передаваемые партнеру, должны шифроваться с помощью TLS/SSL (TLS 1.3).
- Ключи шифрования хранятся в защищённых аппаратных модулях (HSM). Доступ к ключам возможен только через защищённый API с двухфакторной аутентификацией. Необходимо Регулярно проводить ротацию ключей (раз в 3-6 месяцев).
- Необходимо предусмотреть логирование всех действий собственника (добавление лица, номера, отправка команды). В логах маскируем персональные данные.
- Необходимо настроить SIEM-систему для оперативного выявления аномалий и попыток несанкционированного доступа. Настроить автоматические алерты в случае подозрительной активности.
- Собственник должен иметь доступ для настройки умного дома только к разрешённым ему точкам входа (домофон, шлагбаум).
- В БД все персональные данные хэшируем, используя токенизацию. Исключить хранение биометрии в явном виде.
- Определен список ролей для доступа к Kubernetes кластеру (пользователю выделяются минимально возможные доступы к компонентам кластера), настроены сетевые политики для ограничения трафика между сервисами.
- Используем DLP систему для внешних вызовов для обнаружения и предотвращения утечек данных. 

### Аутентификация, авторизация:
- Между системой предприятия и внешним партнером используется OAuth2.0.
- Аутентификация пользователей происходит через текущую систему (KeyCloak c поддержкой MFA, Active Directory)
- Собственник имеет доступ только к доступным точкам входа (домофону, шлагбауму).

### Взаимодействие между системами предприятия и внешней платформой
#### Схема взаимодействия при открытии домофона
* Собственник открывает мобильное приложение и загружает фотографию лица.
* Мобильное приложение передаёт фото на сервер PropDevelopment через зашифрованное соединение (HTTPS, TLS 1.3).
* На сервере происходит обработка изображения и преобразование фото в биометрический шаблон
* Биометрический шаблон шифруется и сохраняется в базе данных PropDevelopment
* Камера домофона фиксирует лицо пользователя
* Изображение передаётся в систему партнера "Умный дом"
* Система "Умного дома" создаёт биометрический шаблон
* Система "Умного дома" отправляет этот шаблон в PropDevelopment для верификации (через API по HTTPS)
* PropDevelopment сравнивает полученный шаблон с данными в своей базе
* Если найдено совпадение, PropDevelopment отправляет ответ партнёру
  * Лицо подтверждено, открыть дверь
  * Лицо не найдено, отказать в доступе
* Система "Умного дома" открывает дверь (если доступ разрешён).
* Все действия логируются в системе PropDevelopment.
