### Требования к безопасности:
- Необходимо реализовать механизм сбора согласия на обработку персональных данных от пользователей
- Специальный договор с партнёром должен включать требования по защите персональных данных (включая обработку, хранение, передачу). Передаем также минимальный набор данных для решения задачи.
- Данные, передаваемые партнеру должны шифроваться с помощью TLS/SSL.
- Ключи шифрования хранятся в защищённых аппаратных модулях (HSM)
- Необходимо предусмотреть логирование всех действий собственника (добавление лица, номера, отправка команды)
- Собственник должен иметь доступ (RBAC) для настройки умного дома только к разрешенным ему точкам входа (домофон, шлагбаум)
- В логах маскируем персональные данные
- В БД все персональные данные хэшируем, используя токенизацию.
- Необходимо настроить SIEM-систему для выявления аномалий и попыток несанкционированного доступа.


### Аутентификация, авторизация:
- Между системой предпрития и внешним партнером используем OAuth2.0
- Аутентификация пользователей происходит через текущую систему (KeyCloak c поддержкой MFA, Active Directory)
- Собственник имеет доступ только к определенным домофону, шлагбауму. Необходимо проводить авторизацию собственника перед осуществлением каких-либо действий в системе Умного Дома.
